# LIMITLESS INTERNET FIBER

This GitHub Pages project contains the existing static website.

## Files
- `index.html` — website homepage.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.

## Data storage
This version does not include Firebase or a cloud database. Bookings, package settings and connection fees are stored in the browser using `localStorage`, so they remain on that browser and device only.
